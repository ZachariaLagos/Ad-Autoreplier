# Outlook 广告邮件识别与自动回复

用一个从零实现的小型 Transformer 判断邮件是不是广告，然后通过 Microsoft Graph API 自动回复感谢信、把广告移到单独的文件夹。

## 文件说明

| 文件 | 作用 |
|---|---|
| `tokenizer.py` | 从零实现的分词器（中文按字、英文按词） |
| `model.py` | 从零实现的多头注意力、Transformer 编码器和分类头 |
| `train.py` | 训练模型，输出准确率、精确率、召回率 |
| `outlook_client.py` | 登录 Outlook 并读取、回复、移动邮件 |
| `collect_data.py` | 从你自己的邮箱导出训练数据 |
| `main.py` | 主程序，定时检查新邮件并处理 |
| `config.py` | 所有设置都在这里 |

## 第一步：安装依赖

    pip install -r requirements.txt

## 第二步：在 Azure 注册一个应用（只需做一次）

Outlook 已经不允许用密码直接登录收发邮件，程序需要通过微软的 OAuth 授权。

1. 打开 https://portal.azure.com ，用你的微软账号登录，搜索并进入 “Microsoft Entra ID” → “应用注册” → “新注册”。如果提示没有目录或租户，可能需要先开通一个免费的 Azure 账号。
2. 名称随意填，“受支持的帐户类型”选择包含 **个人 Microsoft 帐户** 的选项，重定向 URI 留空，点注册。
3. 在左侧 “身份验证” 页面最下方，把 “允许公共客户端流” 设为 **是**，保存。
4. 在 “API 权限” → “添加权限” → “Microsoft Graph” → “委托的权限”，勾选 `Mail.ReadWrite` 和 `Mail.Send`。
5. 回到 “概述” 页面，复制 “应用程序(客户端) ID”，填到 `config.py` 的 `CLIENT_ID`。

第一次运行时，终端会显示一个网址和验证码，在浏览器里打开、输入代码并登录即可，之后会自动记住登录状态（保存在 `token_cache.json`，不要分享这个文件）。

## 第三步：准备训练数据

在 Outlook 里新建一个名为 “广告” 的文件夹，把几百封广告邮件拖进去，并确保收件箱里剩下的大多是正常邮件。然后运行：

    python collect_data.py

会生成 `data.csv`，两列分别是 `text` 和 `label`（1 是广告，0 是正常）。你也可以把公开的垃圾邮件数据集整理成同样格式合并进来，数据越多效果越好；两类各有几百封就能看到不错的效果。

## 第四步：训练

    python train.py --epochs 10

在普通电脑的 CPU 上通常几分钟就能跑完。重点看 **精确率**：它表示被判成广告的邮件里有多少真是广告，这个数越高，正常邮件被误回复的风险越低。

## 第五步：试运行

`config.py` 里默认 `DRY_RUN = True`，此时只打印判断结果，不会改动任何邮件：

    python main.py

检查输出，如果有正常邮件被误判成广告，可以调高 `AD_THRESHOLD`，或补充更多数据重新训练。

## 第六步：正式运行

确认准确后，在 `config.py` 里把 `DRY_RUN` 改成 `False`。默认只会把广告移到 “广告” 文件夹；如果确实想回复感谢信，再把 `SEND_REPLY` 改成 `True`。程序会每 5 分钟检查一次未读邮件。

内置的保护措施：同一个发件人只回复一次；`noreply` 之类的地址不回复；每轮最多回复 10 封；处理过的邮件记录在 `state.json`，不会重复处理。

## 可以继续尝试的方向

把 `train.py` 里的 `d_model`、`n_layers` 调大看看效果变化；在 `model.py` 里打印注意力权重，观察模型关注了哪些字词；或者把分类结果扩展成多类（广告、通知、私人邮件等）。
